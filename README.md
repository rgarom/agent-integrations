# Nextplan para Codex

Marketplace público del plugin oficial de [nextplan](https://www.nextplan.es/asistentes).

```bash
codex plugin marketplace add rgarom/nextplan-marketplace
codex plugin add nextplan@nextplan
```

Abre una tarea nueva después de instalarlo. Las búsquedas públicas no requieren cuenta. Los planes guardados necesitan una clave personal creada en [nextplan.es/cuenta/conexiones](https://www.nextplan.es/cuenta/conexiones).
